# 04 · 蓝图规格说明（给内网模型看）

> 你（模型）只做一件事：**把需求文档写成声明式 JSON 蓝图**，放到 `blueprints/` 下。
> 不写 HTML、不写 CSS、不写 JS、不改 `foundry/` 下任何文件。
> 写完后由人执行 `node engine/prism.mjs lint`，报错按第 7 节改，error 清零才算完成。

## 1. 铁律（逐条遵守）

1. 只能用第 4 节的 19 个组件，组件名拼错会编译失败。
2. 蓝图中**不允许出现任何色值、字号、间距、圆角、布局描述**；样式只来自样式宪章。
3. 页面结构 = `scenes`（状态）+ 每个 scene 的 `blocks`（区块序列）；不要写 DOM 标签。
4. 所有交互写成 `act` 动作串数组，不要写事件处理代码。
5. 每个 `navigate:` 的目标必须是已存在的页面 id（或 `../index` 回门户）。
6. 每个 `scene:` / `dialog:` / `drawer:` / `form:validate:` 的目标必须在本蓝图里存在。
7. 动作串用 `|` 分隔多个动作，**文案里不要出现竖线**；也不要在一条动作串里塞 `|` 拼接的字符串。
8. 不确定某个组件怎么用时，查第 4 节或看 `blueprints/` 里已有蓝图，不要猜、不要自创组件。
9. 批量页面不要逐页手写，改 `examples/batch-matrix.json`，由 `expand` 生成。
10. 可选字段 `generator.model` 只能是第 8 节白名单里的五个模型之一。

## 2. 蓝图顶层字段

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | ✓ | string | 页面 id，同时是输出文件名 `pages/<id>.html`；全局唯一 |
| `title` | ✓ | string | 页面标题 |
| `group` | | string | 侧栏分组名（不填归到「其他」） |
| `scenario` | ✓ | string | `existing-optimization` / `new-feature` / `batch` |
| `batchGroup` | | string | 批量组名；同组页面结构指纹必须一致 |
| `order` | | number | 侧栏排序，小的在前 |
| `nav` | | boolean | 是否进侧栏导航，默认 true |
| `breadcrumb` | | string[] | 面包屑，最后一项自动加粗 |
| `summary` | | string | 页面说明，显示在页脚 |
| `source` | | object | `{ requirement, baseline, reference, componentLib }`，写清需求来源 |
| `generator` | | object | `{ model, stage }`，模型白名单见第 8 节 |
| `defaultScene` | | string | 默认状态名，缺省 `default` |
| `scenes` | ✓ | object | 见第 3 节 |
| `overlays` | | array | 弹层，见第 5 节 |

## 3. 场景 `scenes`

键 = 状态名，值 = `{ label, blocks, note }`。

```json
"scenes": {
  "default": { "label": "常规列表", "blocks": [ ... ], "note": "可选说明" },
  "loading": { "label": "加载中", "blocks": [ ... ] },
  "empty":   { "label": "空数据", "blocks": [ ... ] }
}
```

- 状态名用小写英文；`label` 是给人看的中文，会出现在自动生成的「交互状态」切换条上。
- 编译器**自动**根据 `scenes` 生成状态切换条，不要在 blocks 里手写 `sceneBar`。
- 每个状态都会被预编译成一个 `.scene` 面板，运行时只切显示，因此状态切换一定能用。
- 建议每个页面至少覆盖：`default` + `loading` + `empty` + `error`（或对应业务状态）。
- `scenario = existing-optimization` 的页面，编译器自动加「显示/隐藏变更标记」工具条；
  需要变更标记的区块自己加 `changed: true`。

## 4. 组件白名单（19 个）

`props` 里 `*` 表示必填。所有 `actions` / `left` / `right` / `foot` / `headExtra` 数组元素都是按钮对象。
按钮对象：`{ label, tone?, size?, disabled?, act: [动作串...] }`；
`tone` 取 `primary` / `danger` / `text` / 省略（默认），`size` 取 `sm` / `lg` / 省略。

| 组件 | 用途 | props |
| --- | --- | --- |
| `pageHead` | 页面标题区 | `title*`, `desc`, `badges[]`, `actions[]` |
| `notice` | 提示条 | `tone`, `title`, `text*` |
| `filterBar` | 筛选区 | `fields[]`, `actions[]`, `note` |
| `toolbar` | 工具条 | `count`, `left[]`, `right[]` |
| `dataTable` | 数据表格 + 分页 | `columns*`, `rows*`, `selectable`, `pager`(object 或 `false`), `rowActs[]`, `opsTitle` |
| `statGrid` | 指标卡组 | `items*` |
| `chartGrid` | 图表占位 | `boxes[]` |
| `descList` | 描述列表 | `items*` |
| `form` | 表单（含校验） | `id*`, `sections[]`, `foot[]` |
| `steps` | 步骤条 | `items*`, `current`, `id` |
| `tabs` | 标签页 | `id*`, `panes*` |
| `sceneBar` | 状态条（一般用不到，编译器自动生成） | `scenes*`, `active`, `label` |
| `emptyState` | 空状态 | `title`, `desc`, `actions[]` |
| `loadingState` | 加载骨架 | `rows`, `text` |
| `successState` | 成功状态 | `title`, `desc`, `actions[]` |
| `diffNote` | 变更说明列表 | `changes*`, `title` |
| `compare` | 新旧对照 | `old*`, `new*`, `oldTitle`, `newTitle` |
| `panel` | 面板容器 | `title`, `body[]`, `headExtra[]`, `padded` |
| `timeline` | 时间线 | `items[]` |

### 4.1 字段对象 `fields[]` / `sections[].fields[]`

| 键 | 说明 |
| --- | --- |
| `label` | 字段中文名 |
| `name` | 字段名（校验时按它找控件） |
| `type` | `input` / `select` / `date` / `textarea` / `checkbox` / `switch` |
| `required` | true 时必填，校验失败标红 |
| `placeholder`、`value`、`hint`、`options[]` | 常规属性 |
| `rule` | `number` / `phone` / `min:N` / `regex:正则` |
| `error` | 校验失败时的中文提示 |

### 4.2 表格 `dataTable`

- `columns`: `[{ key, title }]`
- `rows`: 每行是对象，值可以是：
  - 字符串 → 普通文本
  - `{ text, sub }` → 主文本 + 次行小字
  - `{ tag, tone }` → 状态标签，`tone` 取 `brand`/`ok`/`warn`/`risk`/`info`
  - `{ link, act }` → 可点击链接
- `pager`: `{ total, page, size }`，或 `false` 表示不显示分页
- `rowActs`: 操作列按钮数组（用 `label` + `act`）

### 4.3 其它常用数据形状

- `badges[]`：`{ text, tone }`，tone 同上
- `tag` tone：`brand` / `ok` / `warn` / `risk` / `info`
- `notice` tone：`info` / `warn` / `risk` / `ok`
- `statGrid.items[]`：`{ label, value, trend, direction }`，`direction: "down"` 表示下降色
- `chartGrid.boxes[]`：`{ title, bars: [数字...] }`
- `descList.items[]` / `compare` / `timeline.items[]`：看 `blueprints/` 里现有蓝图，形状固定
- `panel.body` / `tabs.panes[].body` / `compare.old` / `compare.new`：都是**区块数组**，可嵌套

## 5. 弹层 `overlays[]`

```json
{ "id": "create", "kind": "dialog", "title": "新增资产",
  "blocks": [ ... ], "foot": [ { "label": "提交", "tone": "primary", "act": ["form:validate:create", "overlay:close", "toast:已提交"] } ] }
```

- `kind`: `dialog`（居中弹窗）或 `drawer`（右侧抽屉）
- `id` 被 `dialog:<id>` / `drawer:<id>` 引用
- 弹层里可以放 `form`，`form:validate:<表单id>` 能正确找到它
- 弹层遮罩、右上角 ×、Esc 都会自动关闭，不用写

## 6. 动作串 `act`（完整语法）

| 动作 | 作用 |
| --- | --- |
| `navigate:<页面id>` / `navigate:<页面id>:<场景>` | 页面跳转 |
| `scene:<场景名>` | 切换状态面板 |
| `dialog:<id>` / `drawer:<id>` | 打开弹层 |
| `dialog:close` / `drawer:close` / `overlay:close` | 关闭弹层 |
| `tab:<组id>:<面板id>` | 切换标签页 |
| `step:<数字>` | 推进步骤条 |
| `toast:<中文文案>` | 顶部轻提示（文案内不要竖线） |
| `form:validate:<表单id>` | 校验输入；失败会中断后续动作 |
| `form:reset:<表单id>` | 重置表单 |
| `wait:<毫秒>` | 等待（用于加载 → 成功的状态剧本，上限 5000） |
| `toggle:<元素id>` | 显示/隐藏元素 |
| `select:all` / `select:none` | 表格全选 / 取消 |
| `diff:on` / `diff:off` | 打开/关闭变更标记 |
| `back` | 返回上一页 |

**状态剧本示例**（多个动作按序执行）：

```json
"act": ["scene:loading", "wait:600", "scene:default", "toast:查询完成"]
```

```json
"act": ["form:validate:plan", "step:2", "scene:step2"]
```

## 7. 报错对照表

| lint 报的错 | 怎么改 |
| --- | --- |
| `未知组件 xxx` | 换成第 4 节白名单里的组件名 |
| `组件 X 缺少必填属性 Y` | 补上 Y |
| `组件 X 的 Y 应为 array` | 值写成 `[...]`，不要写字符串 |
| `动作 scene:xxx 指向不存在的场景` | 在 `scenes` 里补该状态，或改动作名 |
| `动作 navigate:xxx 指向不存在的页面` | 目标页蓝图不存在；补蓝图或改目标 |
| `动作 dialog:xxx 指向不存在的弹层` | 在 `overlays` 里补该 id |
| `校验了不存在的表单 xxx` | `form` 组件的 `id` 与动作里的表单 id 不一致 |
| `蓝图里出现样式描述` | 删掉色值/字号/间距；样式由宪章负责 |
| `使用了清单外模型` | `generator.model` 改成第 8 节五个之一 |
| `动作串含竖线` | 文案里去掉 `|`，或拆成多条动作 |
| `批量组出现 N 种不同结构` | 批量页只能改数据，不能增删区块或 props 键 |

```json
        { "component": "panel", "props": { "title": "列表", "body": [
          { "component": "dataTable", "props": {
            "columns": [ { "key": "name", "title": "名称" }, { "key": "state", "title": "状态" } ],
            "rows": [ { "name": "示例 A", "state": { "tag": "在运", "tone": "ok" } } ],
            "selectable": false, "pager": false,

      "label": "加载中",

    }
  }
}
```
