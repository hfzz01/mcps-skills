# 需求文档 · 新增功能：智能巡检编排

> 示例输入。全新功能，存量系统没有可对照的页面；一致性完全由编译期保证。

## 1. 业务目标

把「人工按经验排巡检单」改成「按资产类型 + 运行状态 + 触发规则自动编排」，
减少漏检，并把编排结果可追溯。

## 2. 功能流程

1. **基础信息**：计划名称、计划编号、巡检类型、开始日期、责任班组、联系人电话、
   是否启用自动派发、备注。名称/编号/类型/开始日期必填，编号至少 4 个字符，
   电话若填写须为 11 位手机号。可存为草稿。
2. **规则配置**：展示已配置规则（编号、名称、适用范围、阈值、状态）；
   支持新增规则（名称、监测指标、阈值、适用资产类型、是否立即启用），
   阈值必须为数字。至少保留 1 条启用规则才可提交。
3. **确认提交**：摘要核对 → 提交 → 加载态 → 成功态 → 查看编排结果看板。

## 3. 结果看板

指标卡（生成巡检单、已完成、异常项、自动派发率）、趋势图占位、
巡检单明细表与详情抽屉；支持刷新、空数据、汇总失败三种状态。

## 4. 交互状态

- 三步之间的前进/后退
- 校验失败（必填留空、编号过短、电话格式错、阈值非数字）
- 草稿态、提交加载中、提交成功
- 结果看板的常规 / 加载 / 空 / 异常

## 5. 一致性约束

新功能不允许出现「看起来像另一个系统」的页面。按钮、表格、标签、弹窗、抽屉、
表单控件必须与存量页面完全同形；配色与字号不新增档位。

## 6. 验收口径

- 三步流程可完整走通，校验错误可在界面上看到标红
- 提交经过加载态再到成功态
- 成功态可跳转到结果看板，看板可跳回编排页与台账页
- 与存量页面并排时不出现风格差异
