# 排坑清单

针对内网 Windows 环境的已知坑位（2026-09 实测记录）。

## 安装阶段

| 坑 | 处理 |
|---|---|
| Node 22 启动失败 | 必须 Node 24。启动前 `export PATH="/path/to/node24:$PATH"` 前置 managed node 24 |
| `pnpm install` 后部分包 `dist/index.js` 缺失，报 `Cannot find package 'xxx'` | 本机安全钩子拦了 npm/pnpm 解压过程的临时文件清理（SAFE_DELETE_BULK 类错误）。删掉 node_modules 重装即可 |
| 内网克隆 GitHub 慢/失败 | 用 hfzz01 账号走 HTTPS；git 已配置 `http.sslBackend schannel` + `http.schannelCheckRevoke false`（curl 对应加 `--ssl-no-revoke`） |
| push 卡死超时 | system 级 `credential.helper=helper-selector` 会静默挂起。绕过：`git -c credential.helper= -c credential.helper=wincred push origin main` |

## 运行阶段

| 坑 | 处理 |
|---|---|
| BYOK 欢迎框弹窗 | 关掉即可。BYOK 是 API-backed，必须有 provider 凭证，内网无 key 场景本来就不走这条路 |
| agent 显示 `available: false` | `curl 127.0.0.1:7456/api/agents` 看 `executablePath` 是否指对；`--version` 探测失败会标 missing |
| 环境变量（如 `CODEBUDDY_BIN`）不生效 | 必须存在于 daemon 进程的环境里。dev 模式重启 daemon 所在 shell；系统级设置后注销重登最稳 |
| 沙箱模式（`OD_SANDBOX_MODE`） | 开启后 `CLAUDE_CONFIG_DIR` 等配置路径会被重映射，套壳可能读不到自己的配置。内网简单起见建议不开沙箱 |
| 任务无流式输出 | 看 daemon 日志里 spawn 的完整命令行，手动重放排查参数兼容性 |

## 推送本仓库相关（维护者备忘）

- 本地 `git status` 显示 `[ahead N]` 但 `git ls-remote origin main` 与本地 HEAD 一致时，
  是 `.git/packed-refs` 写入受限导致 remote-tracking ref 未刷新的**显示问题**，
  远端实际正常，直接 push 即可。
- 验证远端真实状态一律用 `git ls-remote origin main`，不信本地 `origin/main`。
